# GAINA 配線指示書プロトタイプ

結線図と配線一覧を並べて、人が確認・編集するための叩き台です。依存パッケージなし。Node.js は構文確認のみ、起動には Python 3 を使います。

## 起動

```sh
cd /workspace/gaina-zumen
npm start
```

ポート 3000 で配信します。`npm run check` で JavaScript の構文確認ができます。

## 操作

- サンプル配線を選ぶと図面の該当線を強調表示
- 配線の追加・編集・削除、検索、確認状態の絞り込み
- 編集して保存すると要確認へ戻り、「確認済みにする」で承認
- 確認済みだけを線色別に並べて UTF-8 BOM付きCSVへ出力（Excelで開けます）
- 印刷は確認済みだけを対象とし、ブラウザでPDF保存可能
- PDF・画像のローカル表示（再読み込み後は再選択が必要）
- 配線情報と案件名はブラウザの localStorage に保存

自動読取、実図面と行の位置連携、Excelの既存書式への出力、認証、サーバー保存は未実装です。サンプル図面は施工用ではありません。実図面と完成Excelを基準に次の開発範囲を決めます。

## 職人用指示書

案件名の右にある「職人用の指示書を作成」を押すと、確認済みの配線を線色別にまとめた専用帳票を表示します。案件名・発行日（日本時間）・作業日・作業者・確認者・線番・接続元・接続先・メモ・施工／照合チェック欄を載せます。印刷・PDF保存に加え、単独で開けるHTMLファイルとして保存できます。未確認配線は含めず、その本数を明示します。

## 相見積・利益管理（別フォルダー）

`procurement/` を開くか、配線画面の「相見積・利益管理」を選択します。

- 照明器具・盤などのメーカー、型番、数量、定価、売価を登録
- 業者別の掛け率・実見積単価・送料・納期を比較（実単価を優先）
- 共通費用を含む税抜粗利率、目標粗利率に必要な売上、業者間価格差を算出
- 依頼用CSVには売価・競合見積・過去仕入額を含めません。メール送信は行いません
- 採用条件を履歴に保存し、同一メーカー・型番の直近実績と比較（発注は行いません）
- メーカー案内のURL・適用日・値上げ率を手動登録。適用日以降に確認して、メーカー名が一致する現在の品目の定価へ反映。基準額と反映額を記録し二重適用を防止。対象品番は公式案内と照合が必要です
- 定価変更時、掛け率で計算する仕入単価は再計算。売価・明示入力した実見積単価・過去実績は据え置き
- JSONバックアップ・読込に対応。保存はブラウザのlocalStorageで、複数案件管理・ユーザー認証・共同編集・メーカー情報自動取得・外部通知は未実装

起動コマンドとNetlifyの公開設定は既存のものを共用します。公開URLの `/procurement/` でアクセスできます。
