# PDF → 結線表（現行）

ルートと `/wiring/` は既存Excel不要の3工程に変更。従来の配線指示書・同型展開アシストは通常画面から外した。仕入・相見積は `/procurement/` に維持。

1. PDFを選ぶ。ページごとに機器枠と端子円を検出し、繰り返し機器の多いページを推奨。対象ページを選択。
2. 機器単位に線色・芯番号、線番、機器端子を確認・編集。元PDFで該当機器を青枠表示。図面にない電線種類・色・相手先は利用者指定。図面から推測しない。
3. 小西様の書式を参考にした新規XLSXを出力。A:B No、C:F MARK、G:K機器、L:R電線種類と図番、S:AV最大10芯、AW:BA相手先。1機器6行で色・線番・機器端子を2行ずつ。11芯以上は次ブロック。元Excel原本の装飾・印刷区切りを完全複製するものではない。

## 実装と限界

PDF.jsで黒系ベクトルの機器矩形・辺に接した端子円を検出。色付き改訂線を除外。線番のPDF文字情報がある場合は優先して転記し、ない場合は近接する線番をTesseract.jsでOCR。機器内の端子台名・端子番号もOCR。元ページと相対座標・OCR原読取を保持。読取値は利用者確認まで候補であり、電気的接続を確定したデータではない。

細字・文字配置・接近した線で誤読が発生する。空欄だけでなく値の入ったセルにも誤りがあり、原図照合が必要。CADの文字がパス化されている場合もOCR対象。スキャン画像は枠認識未対応。斜線・非矩形記号・交点接続・他ページ接続は追跡しない。未検出機器もあり、端子数は読取正答数ではない。現在の位置・回転の想定を外れる表記は読み取れない。選択ページ内全配線の網羅を保証しない。

未確認機器があればExcelヘッダー・ファイル名は確認用。黄色セルは未読取または図面記載なし。確認済チェックは利用者の照合記録であり機械精度の保証ではない。読取根拠シートに元読取と編集後の値、出力についてシートに範囲・制限を記載。

入力PDFと抽出値はメモリー上で処理、外部APIに送らない。ページの再読み込みで消えるのでExcel出力が必要。40MB・100ページまで。端子英数字のみ、和文機器名OCRは未対応。公開サンプルは架空PDF3機器18端子で、原本Excelを答えとして参照せず同じエンジンで処理。

## 検証

`npm test` / `npm run check` / `npm run test:wiring-browser`。幾何抽出・11芯以上の横並び書式・未読取色・根拠シートをテスト。ブラウザーはPDFだけを入力して3機器18明細を生成し、編集値がG3/L3/S5/S7の対応セルに出力されること、未指定色が空欄なこと、モバイル横はみ出しがないこと、ファイルの外部通信がないことを確認。
