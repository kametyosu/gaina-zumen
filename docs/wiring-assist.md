# 結線表アシスト — 対応内容と確認方法

公開画面：`/wiring/`。以前の18明細デモからも開けます。公開サンプルは架空の3台・18芯で、受領した原本、顧客名、機器一覧、画像を埋め込んでいません。

## 解決する作業

ケーブル単位の横持ちExcelを「機器・ケーブル・芯線」に構造化し、色／芯番号・線番・機器端子と元セルを保持します。同じ型の機器について、照合済みの基準から**端子対応だけ**を候補展開。固有の線番・色・機器名は変更しません。図番から確認ページを絞り、再入力と原図を探す回数を減らす試作です。

本書・公開コードには受領した実データの値やファイルを含めません。実データの分析と候補表は、公開フォルダーと別の場所で作成しています。

## 利用手順

1. 「取り込む」で、既存の結線表XLSXを選択。
2. 元のPDFを選択。各ページの図番を確認・手動訂正できます。
3. 「確認を絞る」で、関連図番・参照図なし・書式上の確認候補を切替。
4. ケーブルを選び、各芯の線番・機器端子を原図と照合。
5. 「原図を照合」でPDFの範囲を選び、必要なら英数字OCRの候補を使う。縦書きは回転可能。移動／範囲選択を切替できます。
6. 基準の1台を照合済みにし、「型を再利用」で同型・端子配列の適合を確認して対象を選択。
7. 差分プレビュー後、「候補として反映」。対象は未照合のままです。
8. 対象を原図照合してから、正規化Excel・CSV・指示書、元の様式への差分反映を出力。

## 読み取るExcelの様式

NO（A列）、MARK（C列）、機器名（G列）、電線種類（L列）、色・芯番号（S/V/Y/AB/AE/AH/AK/AN/AQ/AT列）、相手先（AW列）を使う横持ち様式に対応。色・芯番号の原則2行下を線番、その2行下を機器端子として認識します。

- 結合セルの範囲内だけ機器名・相手先を継承。単なる空欄を任意に前行で補完しません。
- 20芯の二段バンクを、機器端子の行と区別します。
- 芯番号と、色欄にある括弧の端子補記を別に保存。
- シールド、明記された別線接地、予備・未割付を別に扱います。
- 共通線番や重複No.を削除しません。IDはシートと元行・セルに基づきます。
- 「旧」で始まるシートは参考として分離。元Excelには保持。
- 括弧付き参照No.は明示して保持し、照合した場合に出力対象となります。物理本数として重複集計しないでください。
- 未割付の芯を勝手に予備芯と断定しません。予備・絶縁の扱いを選ぶか、使用する線番・端子を入力してから照合。

XLSXは20MB、各シート1万行・200列以内（対応欄は先頭60列）。別レイアウトは専用の取込ルールが必要です。確認候補は記載ミスの確定件数ではなく、書式未対応・継続・別線接地等の確認も含みます。

## PDF・OCRの範囲

PDFは40MB・100ページ以内。PDF.jsでページを表示し、図番・注記を読みます。文字が分割された図番も正規化し、手動対応を残せます。図番の一致は、線の接続や機器の一致を保証しません。

本文文字が輪郭線の場合も、選択範囲を高解像度で再描画し、Tesseract英語モデルで英数字候補を抽出します。OCR候補は編集してから芯欄へ割り当てます。PDF名・ページ・図番・正規化した範囲・向き・読取日時を保持。人による照合後に確認状態を更新します。

日本語機器名のOCR、線の自動追跡、機器記号・接続経路の理解、電気的な施工適否の自動判断は未実装です。色は入力Excelの記載で、図面から推測した値として扱いません。

## 保存・出力

- 原本はブラウザ内のFile、取引内容はメモリー上で処理。「端末に保存」でIndexedDB `gaina-wiring-assist` へ原本と照合記録を保存。
- 再読込後の「保存したデータ」で復元。サンプルと実データの保存キーは別。
- モデル・実行コードは自サイトから取得しますが、原本・OCR画像・読取文字を外部APIへ送信しません。英数字OCRは端末のCPUで動きます。
- 正規化Excel・CSVは照合済みだけ。元セル、参照図番、参照区分、照合根拠、PDF候補のページ・範囲・照合日時も出力します。
- 同じ線番の複数芯を省略しません。未照合の一括展開は出力しません。
- 元様式への反映は原本ZIPの指定セルXMLだけを書換え。元のスタイル・結合・印刷設定・他シートのXMLは再生成せず保持し、更新履歴を追加します。
- 元様式に機器端子の行がない場合は勝手に位置を決めず、正規化Excelでの出力を案内します。
- 原本そのものは変更しません。元の値と取込時の値が違えば反映を停止します。

会社別ログイン・クラウド共有・複数端末の競合制御・外部AI・CAD連携・施工承認ワークフローは、この単独利用プロトタイプには含まれません。ブラウザデータの消去で端末保存も失われるため、原本と出力ファイルは別途保管してください。

## 確認済みの事項

`npm test`：芯数・対数、括弧補記、共通線、20芯バンク、結合の継承、範囲外の補完防止、図番正規化、未照合出力の除外、同型適合・候補競合、予備芯への誤展開防止、元セル以外のXML保持。

`npm run test:wiring-browser`：架空データで、基準6芯→2台12セルの候補展開、照合済みだけのXLSX、元様式の値・フォント保持、実PDFの描画、端末内の英数字OCR、保存復元、スマートフォン幅、外部宛てファイル要求がないことを確認。Chromiumが必要です（`CHROMIUM_PATH`で指定可）。

受領ファイルも公開物と別の場所で検証し、Excel構造の読取・8ページの図番対応・指定セルのみの反映を確認しています。全接続の原図一致や作業時間の削減率を測定したものではありません。次の評価では20ケーブル程度で従来作業と入力・確認・修正時間を比較してください。
